## Users

Game studio recruiters, HR leads, technical directors, project clients, and game dev peers looking to hire or contract a Lead Unity Developer / Game Programmer.

## Product Purpose

A personal portfolio website that authentically showcases Dimas Rizky AF's 4+ years of professional game development experience, published titles across Steam (PC), Android, iOS, and WebGL, core technical architecture skills, and official industry credentials.

## Positioning

"Unity Lead Game Developer & Game Programmer" specializing in scalable MVP/VContainer architecture, real-time multiplayer netcode (AWS GameLift, Unity Netcode, Photon, WebSockets), custom package engineering, and mobile performance optimization.

## Operating Context

Evaluated on desktop browsers (Windows / macOS) and mobile devices. Visitors scan technical achievements, review project highlights with video streams & galleries, play an embedded retro Tetris arcade minigame, listen to an authentic Cyberpunk Chiptune soundtrack, and contact via direct links (Email, WhatsApp, GitHub, LinkedIn).

## Capabilities and Constraints

- **Stack**: Pure Vanilla HTML5, CSS3 (Custom Cyberpunk Pixel & HUD Design System), and JavaScript (ES6+ Modular Engine Classes).
- **Libraries**: Three.js (r160 3D wireframe canvas), GSAP 3.12 (ScrollTrigger scanline & reveal animations), canvas-confetti (celebratory FX), Web Audio API (procedural SFX + HTML5 BGM streaming).
- **Audio Engine**: Integrated Cyberpunk 2077 Chiptune Soundtrack (`assets/audio/cyberpunk_bgm.mp3`) with soft volume balancing (15%), Web Audio UI click/hover SFX, mobile autoplay touch unlock, and background tab battery saver.
- **Arcade Minigame**: Fully functional Tetris engine with complete loop (Start → Gameplay with rotation, line clears, levels → Game Over → LocalStorage High Score → Retry) featuring desktop keyboard and mobile touch controls.
- **Constraint**: Static file architecture (zero backend requirement), deployed on static hosting (GitHub Pages, Netlify, Vercel).
- **Design Philosophy**: Cyberpunk Pixel Arcade HUD aesthetic; content remains grounded and 1:1 aligned with official CV; animations serve a clear purpose (scroll reveal, scanline sweep) rather than excessive decoration.
